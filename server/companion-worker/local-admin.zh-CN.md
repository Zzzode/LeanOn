# 合成数据本机运营命令

简体中文 · [English](local-admin.md)

此 CLI 补齐既有 `admin.ts` 函数的本机操作入口。
它不登录 Cloudflare、不读取提供方凭据、不连接远端目标。
仅使用公开虚构数据，不是生产管理执行器。
没有引入新的恢复策略、原生迁移 UI 或后端密码学。

## 设置与命令

使用仓库固定的 pnpm11 构建既有工作区依赖及本包。
从本包目录将 `templates/local-admin.example.json` 复制为私有参数文件。
工作目录必须是系统临时目录或 `/tmp` 下新建的绝对路径，命名为 `leanon-admin-synthetic-<唯一后缀>`。
模板的全零服务ID是占位值；暂存前须改为初始化返回的目标公开服务ID。

```sh
node scripts/local-admin.mjs init --config /tmp/local-admin-parameters.json
node scripts/local-admin.mjs init --config /tmp/local-admin-parameters.json --local-execute
```

所有子命令默认 dry-run，也可显式传入 `--dry-run`。
`--execute`、`--remote`、提供方/账号参数、多余参数及未声明的配置字段均拒绝。
`init --local-execute` 创建权限0700的全新合成目录和两个空的本地 D1/R2 集合，输出公开服务身份后关闭两个运行时。
它不会生成运营加密密钥、准入令牌、账号或生产凭据。
需要迁移时，只向该自有目录放入公开虚构的32字节二进制测试密钥（权限0600）及旧文件后端 JSON fixture。
密钥、快照和删除基线必须位于独立目录；模板使用 `keys/`、`backups/` 和 `floors/`。
状态目录与输入/输出不得重叠；拒绝路径穿越、绝对文件路径、软链接和超大输入。

| 子命令 | 默认预览 | 显式 `--local-execute` |
|---|---|---|
| `init` | 验证全新临时目录，不写入 | 初始化本机源/目标集合，返回公开身份 |
| `backup` | 验证范围、停写声明、密钥长度/权限及未使用的输出 | 导出源集合的认证加密快照和客户端密文对象 |
| `deletion-floor` | 验证范围/密钥及未使用的独立输出 | 导出源集合当前认证删除/撤权基线 |
| `restore` | 验证有界信封/对象编码及路径，明确标示未做认证/数据库检查 | 调用既有核心认证，要求空目标或同一中断导入，并保留删除/撤权栅栏 |
| `migration-plan` | 验证真实旧后端格式，只输出计数 | 拒绝，该命令始终只预览 |
| `migration-stage` | 验证来源、操作和本机地址字段，只输出计数 | 检查真实本地目标的持久服务ID，再暂存身份/授权及重新发布任务 |

预览不创建模拟运行时、不打开 D1/R2、不写文件或锁。
恢复预览成功不表示密文认证、最新权威删除基线或空目标检查已通过。
这些检查在显式本机执行时完成，JSON结果明确区分。
地址只是本机规划标签，不是 CLI 会访问的 HTTP 目的地；执行绑定指定临时集合及其核实的服务ID。
本机 workerd 禁用遥测、公开路由及出站请求；所有打开的运行时均在 `finally` 关闭。

## 保留与失败处理

先停止合成客户端和 cron，再声明 `quiesced: true`。
执行取得独占工作目录锁，各操作顺序运行。
导出原子发布完整的0600文件，不覆盖已有输出。
每次导出基线使用新文件名，恢复参数指向独立保存的最新基线。
旧快照加旧基线不能证明之后没有删除。
操作抛错后释放本次锁；D1恢复中断时保持既有 HTTP/cron 维护门禁，只可使用同一认证输入继续。
导入前的 R2 故障可在隔离目标留下不可访问对象；不会采用源数据或权限行，同一认证恢复可以重试。
强制杀进程可能留下 `.local-admin.lock`，之后执行会拒绝。
确认记录的进程已结束、检查合成检查点后，只清除该自有过期锁再重试；没有自动抢锁。
初始化失败仅删除本次新建的工作目录。
CLI输出仅为有界 JSON：公开身份/计数/状态或固定错误码，不输出原始异常、密钥、验证器、令牌、账号名、清单或密文。

每份运营备份限64 MiB、基线24 MiB、旧输入16 MiB，快照对象最多64个。
序列化快照前也拒绝超过48 MiB的原始对象总量或超过16 MiB的清单。
明确拒绝更大集合，流式/分块设计仍需另行完成。
保留旧集合/服务直到两个人都完成原生迁移；CLI暂存不等于原生重新发布或生产切换。

## 验证与清理

`pnpm --filter @zzzode/companion-worker test` 通过同一命令核心测试真实隔离 Miniflare/workerd D1/R2。
覆盖默认预览文件指纹/无绑定、模板/远端/路径拒绝、错误输出过滤、目标身份不符、密文对象恢复、删除ACK后的最新基线、过旧/篡改/缺失输入及 D1 中断继续。
测试关闭运行时，只删除各自新建的合成目录。
检查后先停客户端再删除自己的工作目录，审查日志留在目录外。
既有 Settings/原生迁移验收独立保留，本轮运营工具改动没有重新执行 UI 验收。
生产账号、费用/CPU预算、数据位置偏好、独立备份/基线/密钥保留及全设备丢失策略仍需用户决定，之后才能实施并验收远端流程。
