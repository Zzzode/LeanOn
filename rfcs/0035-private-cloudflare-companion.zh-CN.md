# 私有 Cloudflare 伙伴中继

[English](0035-private-cloudflare-companion.md) · 简体中文

## 摘要

新增独立 Worker API，D1 使用规范化行保存身份和小密文，私有 R2 保存独立加密照片，只允许两位明确准入的人使用。
保留旧文件中继作协议回归和离线开发。

## 动机与使用体验

整份 JSON、文件锁与内存会话不能提供 Worker 的持久性和并发模型；聚合照片密文也不适合 D1 行与请求预算。
管理员预置两个限时、绑定登录名的准入席位，只存凭证哈希；注册原子消费席位。
家庭／设备邀请仍需创建者确认，不能用于第三人注册。
会话持久化但只存令牌哈希，30分钟过期，登出或撤权即失效。
双端协商照片新协议，旧本机中继维持原协议；Worker 不获得健康解密密钥。

## 设计

- 独立 `server/companion-worker`，兼容日期 `2026-10-07`，严格 TypeScript，使用官方 Wrangler／Miniflare 本地运行。
- D1 分表保存账号、设备、会话、两席准入、组／成员／授权、邀请、当前记录、重放／nonce／送达、照片预留／引用及删除任务。
- 授权读之前记录修订号；D1 批次先作 CAS，失败使整批回滚，不复制一整份 JSON 状态。
- 控制请求、小密文、同步批次、对象和单轮清理设明确上限，超限先拒绝后写入。
- 新密码使用版本化 scrypt `N=16384,r=8,p=5`、随机16字节 salt、64字节输出；迁入旧 `p=1` 仅兼容校验，成功认证后升级。
  不因免费 CPU 限制减弱参数；此组合由 [OWASP](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)列出。
- 每个照片对象使用独立 HKDF 派生密钥、随机12字节 AES-GCM nonce，AAD 绑定组、epoch、账号、设备和随机对象 ID。
  小密文索引认证对象引用；相同 ID 只接受相同密文重放。
- R2 私有，仅经授权 Worker 读取，不提供公开 URL 或可缓存响应。
- 先在 D1 预留随机对象，再写 R2 并确认就绪；未引用预留到期进入持久清理任务。
- 上传仅条件创建不可变对象；撤权用同 key 的零字节栅栏替换密文字节，使迟到上传不能复活。
  栅栏只保留随机路由信息，不得由生命周期策略删除。
- 删账号先原子撤会话／成员权限并落证明哈希任务，再分批清对象。
  全部密文清理完成才返回既有严格 `deleted` 回执并允许 ACK；同 Worker 定时恢复，故障保留任务。
- 独立管理员备份密钥认证 D1／索引／R2 清单；恢复必须提供权威最新删除基线，保留栅栏和撤销，拒缺失／篡改对象且不恢复活会话。
  E2EE 密钥仍由原生伴侣存储／密钥环持有；既有可移植健康备份不导出伴侣密钥，服务器备份／密码本身不能恢复密钥。

- 旧聚合迁移只暂存身份/授权、提高 epoch、建立待完成任务，保留旧密文及原集合。
  原生客户端复用现有加密健康备份，轮换操作绑定密钥，在独立空集合重新发布独立对象。
  加密阶段日志和同密文重试保证中断可恢复，服务端引用检查后才完成；双平台演练验证中断后新授权设备完整健康恢复。
  全设备丢失时，既有健康备份只恢复其快照；上线前需决定新密钥/重新配对重置政策，或另审伴侣密钥恢复方案。

## 已授权产品迁移入口

Settings通过既有主题/表单组件调用原生预览、准备、恢复、暂停和回退action。
确认绑定持久目标服务标识、认证后的原账号/设备ID、操作ID、本地修订号及短期预览token。
密码仅临时持有；源快照由既有加密备份和设备绑定阶段日志保留。
独立加密目标集合重新发布后，经既有原生事务和实体合并，一并切换伴侣状态和本地记录。
源连接状态保留在加密日志；回退保留当前本机健康内容，恢复源连接且不删除目标。
取消在切换前的安全检查点暂停；重启不自动恢复上传。
dry-run管理工具只验证旧输入/目标身份并生成配置及操作计划，不含远端写入或提供方登录路径。
本范围复用授权设备/健康备份，不新增全设备丢失恢复政策。

## 代价与替代方案

D1／R2 不跨库原子，预留、栅栏与任务增加状态；零字节栅栏故意长期保留。
密码计算预计超过 Workers Free 的10ms CPU；本机 workerd 不能证明远端可行性，部署须另选安全 CPU 预算或身份提供商，不能减弱哈希。
备份保留与恢复流程须保护权威删除基线。
两人产品使用同一个 Worker 和定时处理器，不无需求增加独立服务。
简单 R2 删除加超时租约不能阻止迟到写入复活；不可变上传和栅栏提供所需顺序。
拒绝公开注册、公开 R2 与默默降低密码参数。
参考：[D1 批次](https://developers.cloudflare.com/d1/worker-api/d1-database/)、[R2 条件写入](https://developers.cloudflare.com/r2/api/workers/workers-api-reference/)、[Worker 限制](https://developers.cloudflare.com/workers/platform/limits/)。

## 待决定及实施

远端 CPU／内存／延迟、区域、计费批准、管理员备份目的地和生产准入预置须另行决定验收。
本 RFC 不授权供应商登录、付费资源、真实数据、部署、提交或推送。
分批实现身份／准入与并发、双端照片／同步、删除／撤权恢复，再做虚构迁移、完整备份恢复和本地性能测量。

## 本地验证补记

离线导入每次事务最多包含 32 条数据写入与检查点，恢复期间 HTTP 和 cron 通过持久化维护门禁关闭。
只有同一份已认证输入可以继续中断恢复。
密码认证增加持久化过期租约，同一时刻只计算一次内存硬哈希，并保留全局及登录名尝试预算。
伴侣 E2EE 密钥位于原生伴侣存储/keyring；既有可移植健康备份不导出这些密钥。
仅有服务器备份和密码无法恢复密钥；全部已批准设备丢失时的密钥导出/恢复仍须另行设计，不能称为已完成。
旧 vault/照片聚合密文不能由服务器安全拆分，因此切换前必须由有密钥的原生客户端完成认证重新发布。
