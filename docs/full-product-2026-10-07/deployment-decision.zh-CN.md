# 生产部署决策草案

[English](deployment-decision.md) · 简体中文

状态：可审查方案；没有建立供应商账号、付费资源、生产端点，没有部署、提交或推送。
当前中继仍是只监听本机回环的开发服务。

## 推荐首期范围

采用邀请制小范围 beta：Fly.io 单台 Machine、一个持久卷、同机 TLS 反向代理。
代理监听8080，转发到现有 Node 中继127.0.0.1:8787。
保留中继默认回环限制，不直接暴露开发监听器。
仅一个写入进程，配置自动重启和就绪检查；不得扩容成多个写入者或多挂载同一状态文件。
回执恢复验收期间关闭自动停机，监测磁盘、内存、回执容量和持久性屏障失败。
先选 shared-cpu-1x/1GB 加1GB卷；按实际最大载荷/压力结果调整内存。
客户端每页四图只限制挂载数量，不限制中继请求缓冲峰值。

这是私有 beta 推荐，不是高可用或公开注册批准。
Fly卷属于单一物理宿主，不会自动复制；单实例遇到磁盘/宿主故障可能停机或丢失数据。
每日快照不能代替独立备份。
依据：[卷限制](https://docs.fly.io/volumes/overview)、[服务及TLS配置](https://docs.fly.io/reference/configuration)。

## 用户最少需确定的事项

1. 批准供应商与付费组织：推荐 Fly.io，估计月预算15美元；这不是平台硬性费用上限，流量、备份和区域另计。
2. 明确首批使用人群与数据驻留区域；建议小范围邀请制 beta、默认供应商域名，注册准入门须先实现验收。
3. 指定独立加密备份目的地／保留／删除恢复策略，并明确允许创建哪些资源及部署；提交／推送另行授权。

费用依区域和用量变化。
当前官方示例：shared-cpu-1x/1GB 在 Ashburn为6.70美元/月，Singapore为8.50美元/月；1GB卷另加0.15美元/月，未计流量和备份。
上面的预算是估计，不是报价或订阅承诺。
依据：[官方价格](https://docs.fly.io/about/pricing)。

## 具体部署前置条件

使用仓库 pnpm/Node22 工具链构建独立中继产物。
将中继与受监督的反向代理打包，以持久卷保存 LEANON_RELAY_FILE。
配置 force_https、区域、至少一台常驻 Machine，禁止多个文件存储写入者并行。
供应商 release command 不挂载应用卷；迁移/恢复演练必须在实际挂载卷和单写入租约下执行。
写入进程运行时不能直接覆盖状态文件。

当前 POST /v1/accounts 允许能访问中继的调用者注册。
家庭/设备邀请不是注册准入门。
推荐的邀请制 beta 还须另行实现并验收网络准入或服务器注册门；TLS／回环转发本身不能提供邀请制。
不能在开放公开注册的同时把此方案描述为已实现的邀请制。

生产批准前须在部署卷验收重启及不确定fsync/rename、代理TLS/跳转/请求体上限、最大载荷内存、磁盘满、带删除墓碑的备份恢复、秘密注入/轮换、日志脱敏、滥用限流和告警。
账户恢复须单独定义：密码不能恢复仅客户端持有的保险库密钥；现有实现仍以已有设备批准为信任模型。
多宿主部署需要事务共享存储及新的存储/部署决策；当前PID租约不是分布式锁。

## 本机工具的实际边界

Docker CLI已安装，但普通只读调用在沙箱中无法访问用户Colima daemon socket。
本工作区未安装Fly CLI。
这不代表可启动/修改全局daemon、安装供应商工具、登录账号或创建付费资源。
目标确定后再准备相应部署产物和供应商验证；生产部署仍待授权。

官方价格、卷和配置页面已于2026-10-07重新核实；本机验收没有创建此方案的资源。
