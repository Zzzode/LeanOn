# LeanOn 设计语言 v3 — 更轻的阅读层级

[English](README.md) · [保留的 v2 提案](../design-language-v2/README.zh-CN.md)

V3 沿用已认可的多色方向，减少填色、重复容器与品牌表达频率。
这是**静态设计提案**，不是已实现应用，也不是新抓取的原生截图。
本轮未改应用源码、业务逻辑、用户记录、原生底栏，未提交或推送。

## 具体调整

| 区域 | V2 | V3 |
|---|---|---|
| Today | 深紫 354 × 194 pt 主卡，三个浅色动作，两个浅色指标卡，营养卡。 | 白底 354 × 176 pt 主卡；一个珊瑚主动作；体重／运动与营养开放排版；颜色留给类别图形和图标。 |
| 颜色语义 | 青蓝／琥珀也表示脂肪／碳水；提醒借用了饮水色。 | 珊瑚饮食、青蓝运动、鸢尾体重、琥珀饮水、玫瑰关系；宏量数值和通用工具中性。葡萄紫负责身份与导航。 |
| 容器 | 大多数分组都有圆角背景。 | Today／Progress／Diary／Me／Settings 各一个主表面；Partner 无大卡。辅助信息靠行和空间分隔；输入仍保留必要边界。 |
| Partner | 大插画、两行粗宣言、状态胶囊、说明卡、强色设置按钮。 | 约 140 pt 成对图形、一行 26 pt／500 文案、直接未开放状态、开放说明、次要设置链接。无虚构伴侣或送达。 |
| Me／Settings | 情绪副标题／色块及等权工具。 | 功能标题；Me 先显示设置／关于，再放未开放工具；去口号、重复头像 Logo 和不可点击箭头。 |
| 表单 | 已选项和热量估算放在色卡里。 | 开放选择行、明确输入边界、一个保存主动作；份量／时长为主数字，热量估算缩小。原生编辑、已有校验与持久化仍是实现要求。 |
| 状态／深色 | 浅色胶囊与满宽次要动作。 | 直接状态标签、内联校验、克制链接、明确保存禁用；深色中性表面配类别点缀。 |

底栏是已认可原生截图的原样静态裁切，玻璃里保留的微弱旧内容不属于新稿。
深色板只示范内容区，原生底栏主题和动画需保留。

## 规则与 token

- 浅色底 `#F8F7F4`，纸面 `#FFFFFF`，主字 `#28242C`，次字 `#69616B`。
- 保留类别色：品牌 `#573C58`、饮食 `#C35445`、运动 `#177D89`、体重 `#7563B1`、饮水 `#BD8532`、关系 `#B75B7B`。
- 文字／主动作使用独立深色 token；不把有意义文字变浅来营造精致感。
- 深色底 `#201D26`、卡面 `#2B2731`、主字 `#FAF5F3`、次字 `#CEC3CE`；完整配色和语义见 `tokens.json`。
- 80–90% 中性构图、约 3–5% 强色作为起点；是设计指导，不是像素统计，也不要求调色板展示板遵守此比例。
- 标题 27 pt／600，常规行 16／400–500，主数字 48–52／500，辅助数字 26–32／500，有意义说明 14；体重输入采用 56 pt。
- 主卡圆角 22、内容 20、控件 12、输入 11；4 pt 网格、边距 24、主要间距 24–32。每个指标不再套卡。
- iOS 点击至少 44 × 44 pt，Android 至少 48 × 48 dp；小图标不等于小点击区域。
- 记录实线与点，拟合虚线，目标中性；缺日断开，不补零；升降不对应好坏色。
- 人情味用于 Today／Partner／合适空态，工具页直接说明功能；“轻一点，靠近一点。”不在每屏重复。
- 按压 120 ms，弹层 180–220 ms，减少动态用淡入；原生底栏行为不变。
