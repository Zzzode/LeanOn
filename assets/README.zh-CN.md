# LeanOn 品牌资产

LeanOn 的 Logo、配色与使用规范。默认语言为英文，中文镜像见 [`README.md`](README.md)。

## 标志含义

LeanOn 帮助两位伴侣一起变得更健康——既能变“**瘦（lean）**”，又能随时彼此“**依靠（lean on）**”。

标志由两片新鲜的叶子相靠、共同构成一颗心：

- **叶子**代表健康、自然与成长；
- **心**代表关爱与陪伴；
- 两个形态轻轻相靠，如同两个人并肩同行。

标志刻意保持简洁——只有一个清晰的整体轮廓，没有小符号或细碎细节——从而在小尺寸下清晰可辨、长期耐看。

## 制图逻辑

- 流畅的几何形态，在 100×100 网格上定义。
- 浅色版使用柔和、通透的绿色渐变；App 图标使用满版绿色底 + 白色标志。
- 不使用在小尺寸下会消失的细小点缀。

## App 图标

- **iOS** 使用 `app-icon-ios-1024.png`：1024×1024、无圆角、无透明通道，圆角由系统统一裁切。
- **Android** 自适应图标（前景/背景分层、66% 安全区）将在原生宿主工作中于 `apps/android` 下生成。

## 使用规范

- 标志四周保留约一片叶子宽度的安全区。
- 最小数字尺寸为 24 px；更小请优先使用满版图标。
- 在照片或杂乱背景上使用满版色块图标。
- 不得拉伸、旋转、使用本规范之外的颜色、添加特效，或重绘形态。
